# Biorritmos

Repositorio para reunir implementaciones de una calculadora de biorritmos en distintos lenguajes y plataformas.

La intención es que cada implementación calcule los ciclos de una persona a partir de su fecha de nacimiento y una fecha de consulta. Los ciclos habituales son:

- físico: 23 días;
- emocional: 28 días;
- intelectual: 33 días.

## Estado del proyecto

El proyecto está en una etapa inicial. Los directorios de cada tecnología están creados para organizar implementaciones futuras; actualmente, solo `react/` contiene un proyecto base, todavía sin el código de la aplicación (`src/`).

## Cómo contribuir

Mantén cada implementación dentro del directorio de su tecnología y añade instrucciones para instalar dependencias, ejecutar el programa y validar los cambios. Si cambia el estado de una implementación, actualiza también la tabla anterior.
