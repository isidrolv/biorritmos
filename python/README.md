# Calculadora de biorritmo

Aplicación de escritorio que calcula y grafica los ciclos físico, emocional e intelectual, junto con los aspectos espiritual, conciencia, intuición y estética, a partir de la fecha de nacimiento.

## Ejecutar

Requiere Python 3.10 o posterior. No necesita instalar dependencias.

```powershell
python app.py
```

La fecha central se puede cambiar con el selector o con los botones **Anterior**, **Hoy** y **Siguiente**. Cada elemento de la leyenda se puede pulsar para mostrar u ocultar su curva. El selector **Tema** permite usar la apariencia del sistema, clara u oscura.

## Pruebas

```powershell
python -m unittest -v
```
